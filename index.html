01 / about
The engineer behind the build

      

        
I build native apps from scratch, and I know when cross-platform is the better choice.

        

          
I write fully native applications: iOS in Swift and Objective-C, and Android in Kotlin and Java, from the first screen to the App Store and Google Play. I also build cross-platform apps in Flutter. Alongside new builds, a large part of my work is keeping enterprise applications healthy: fixing what breaks, shipping new features into mature codebases, and keeping releases predictable.

          
I also lead modernization. I embed Flutter modules inside existing native apps, wire them up through platform channels, and move features across until the app is ready to run on a single, shared codebase.

          
I use AI-assisted development and agentic coding tools every day to read unfamiliar code faster, refactor safely, and spend my time on the decisions that matter.
